# Ch08 - Objects

So far every value has stood on its own: a name, a price, a flag. Real things have several facts about them at once. A customer has a name, a city, and an age. An order has an ID, a buyer, and a list of items. An object groups those facts under one name, and this chapter covers how to build, read, change, and nest them, and how to give them a type.

## What you'll learn

1. How to build an object, and read its parts with a dot or with brackets.
2. How to change an object's parts, and add new ones.
3. What a type for an object looks like, and what a record is.
4. How objects sit inside other objects.
5. How to list an object's names and values, using the tools built into JavaScript.

The chapter ends with a summary, and two homework exercises.
