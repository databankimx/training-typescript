# Ch05 · Booleans and missing values

Programs are constantly asking questions: is the user logged in, is the form complete, is the price above the limit. The answers are yes or no, and the type that holds them is `boolean`. This chapter is about asking those questions well, combining the answers, and dealing with the awkward case where there's no answer at all.

## What you'll learn

1. What a boolean is, and how to store one.
2. How comparisons produce booleans, and why `===` is the one to trust.
3. Which values count as yes and which count as no, when a program checks a value directly.
4. How `&&`, `||`, and `!` combine answers, and how defaults are chosen with `??`.
5. What `null` and `undefined` mean, and how to work with a value that might be missing.

The chapter ends with a summary, and two homework exercises.
