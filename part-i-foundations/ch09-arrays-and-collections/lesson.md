# Ch09 · Arrays and collections

Most programs work with more than one of something: a list of orders, a set of prices, a grid of seat numbers, a lookup table of customers by ID. An array holds an ordered list of values, and TypeScript gives you the tools to describe, change, and transform them. This chapter also covers two other collections, maps and sets, for the cases where an array isn't the right shape.

## What you'll learn

1. How to build an array, read an item by its position, and add to it.
2. How to transform a list with `map`, `filter`, and `find`.
3. How to put lists inside lists, for grids and tables.
4. How tuples describe a list of fixed length, and how destructuring pulls its parts out.
5. How maps look things up by key, and how sets keep each value once.

The chapter ends with a summary, and two homework exercises.
