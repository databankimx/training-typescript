## Summary: Getting started

These are the basic ideas the rest of the course builds on.

* **A program is a list of instructions.** The computer carries them out one at a time, from the first line to the last.
* **Values are pieces of data.** A value can be a number, such as `1300000`, or text, such as `"Dallas"`. The quotes are what make text different: they show where the text starts and ends.
* **Printing shows what the program did.** `console.log` displays the values you give it, and that's how you see the result.
* **Check and Run do different things.** Run starts the program. Check reads the code and looks for mistakes, without running it.
* **An error is a message about a mistake.** The first line says what went wrong, and where. Read that line first.
* **A comment is a note for people.** The program skips it, so use comments to explain why the code is written the way it is.

### Check your understanding

*These questions are written for this course.*

```quiz
When you press Run, in what order does the computer carry out a program's instructions?
○ In a random order.
→ Not quite. A program's instructions run in the order they're written.
◉ From the first line to the last, one at a time.
→ Right. A program runs its instructions in order, from top to bottom.
○ All at once.
→ Not quite. Each instruction runs after the one before it has finished.
```

```quiz
Which of these is text rather than a number?
○ 1300000
→ Not quite. Without quotes, that's a number, and you can calculate with it.
◉ "1300000"
→ Right. The quotes make it text, even though it looks like a number.
○ 1300000 * 2
→ Not quite. That's a calculation, which produces a number.
```

```quiz
What does Check do that Run doesn't?
○ It starts the program, and shows its output.
→ Not quite. That's what Run does.
◉ It reads the code and reports mistakes, without running the program.
→ Right. Check looks at the code, so it can find mistakes before the program runs.
○ It saves the code to a file.
→ Not quite. The code is saved separately, and Check doesn't save anything.
```
