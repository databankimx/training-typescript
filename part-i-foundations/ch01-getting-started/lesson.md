# Ch01 · Getting started

Every course has a first day, which is usually spent discovering where the coffee is. This chapter is ours. You'll install the tools, run a program, and learn to read the messages that appear when something goes wrong, which turns out to be most of the job.

This course assumes you're starting from a complete introductory course. You don't need to know TypeScript before you begin, but you do need to know a little JavaScript, because TypeScript adds types to JavaScript. Every example here is valid JavaScript with a few extra words added.

## If you're new to JavaScript

Work through the JavaScript training course first, then come back here. It covers the language from the beginning, and it uses the same kind of runner:

- Repository: [https://github.com/databankimx/training-javascript](https://github.com/databankimx/training-javascript)
- Start with its Part I, Fundamentals.

You'll need to be comfortable with variables, functions, arrays, objects, and conditions. Those are the things TypeScript adds types to, so they're the things this course depends on.

## If you already know JavaScript

Skip ahead to the first step in this chapter. Each step names the JavaScript it relies on in its first paragraph, so you can check you're ready.

## What you need installed

Node.js 24 or later, and VS Code. The setup script in the repository root checks for both, and installs them if you run it from an Administrator PowerShell.

## What this chapter covers

You'll run your first program, learn how values and printing work, and learn to read the messages the tools give you. Each step adds one basic idea, and the chapter ends with a summary of them.
