# Ch06 · Choices

Programs make decisions all day long. If the payment went through, send the receipt. If the form is incomplete, show the error. If the light is red, stop. This chapter covers the tools for writing those decisions: `if`, `else`, the short form that fits on one line, and `switch` for choosing between many named cases.

## What you'll learn

1. How an `if` statement runs one block of code or another.
2. How `else if` handles a list of ranges, such as grade bands.
3. How the conditional operator makes a choice inside an expression.
4. How `switch` chooses between named cases, and why `break` matters.
5. How to nest choices, and when a flat list reads better.

The chapter ends with a summary, and two homework exercises.
