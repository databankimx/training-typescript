# Ch10 · Functions

You've been calling functions since the first chapter: `console.log`, `trim`, `Math.round`. A function is a named set of instructions you can use again, with inputs and an output. This chapter covers writing your own: how to give them parameters and defaults, how to return results, and how the type labels describe what goes in and what comes out.

## What you'll learn

1. How to define a function, give it parameters, and call it.
2. How parameters can be optional or have defaults, and what the checker says about each.
3. How return values work, including functions that return nothing.
4. How arrow functions give a shorter form, used with the array methods from the last chapter.
5. How a function can be passed to another function, and what scope means for the names inside one.

The chapter ends with a summary, and two homework exercises.
