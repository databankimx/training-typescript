# Ch07 - Loops

Some jobs are repetitive by nature: print every line of a report, add up every price in a basket, try again until the connection works. A loop runs a block of code again and again, and this chapter covers the common forms, how to stop one early, and how to put a loop inside another.

## What you'll learn

1. How a `while` loop repeats while a condition holds.
2. How a `for` loop keeps its counter in one place.
3. How `for...of` visits each item in a list, and `for...in` visits each name in an object.
4. How `break` leaves a loop, and `continue` skips to the next item.
5. How loops nest, and why the inner loop runs in full for each step of the outer one.

The chapter ends with a summary, and two homework exercises.
