# Ch22 - Dynamic forms

Many forms are not fixed. A shopping list grows as the learner adds items, a table row is removed, a long list is narrowed down by typing into a filter, and the rows are reordered by a column. The page changes after it loads, so the script has to create, remove, show, hide, and reorder elements, and keep each row's data and its element in step. This chapter covers those four jobs.

These lessons are page steps, as before. Press **Run** to open the page in its own window, and use the **File** drop-down to edit the page's HTML and CSS as well as its script.

## What you'll learn

1. How to add a new element to a page each time the learner asks for one.
2. How to remove an element when its own button is pressed, with one handler for the whole list.
3. How to show and hide rows as the learner types, and how to read their text safely.
4. How to sort the data and redraw the rows from it, so the page always matches the data.

The chapter ends with a summary, and two homework exercises.
