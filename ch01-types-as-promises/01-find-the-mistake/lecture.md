# Lecture notes: find the mistake before it runs

## Slide outline

1. A helper that works on numbers, and a call that passes text.
2. The prediction: what does JavaScript print?
3. The same code with a type, and the error it gives.
4. Run versus check: Node runs the file, and the checker reads it.

## Discussion questions

- Where in your own code do values arrive as text, and who converts them?
- If a type error doesn't stop the program, what stops it from reaching a user?
- Would you rather have the check run in your editor, at the terminal, or in the build? What does each one cost?

## Pairing suggestion

One person predicts, and the other person runs the check before the run. Swap roles for the second example. Ask the pair to write one sentence describing what the checker told them that the program didn't.
