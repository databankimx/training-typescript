# Ch14 · Classes

A class is a blueprint for objects that belong together. An account has an owner and a balance, and it knows how to deposit and withdraw. Classes group the data and the actions on that data in one place, so the rules about an account live with the account. This chapter covers how to write a class, how methods change its state, how to hide details from other code, how a class can promise a set of methods, and how one class can extend another.

## What you'll learn

1. How to define a class with properties and a constructor, and create objects from it.
2. How methods change an object's state, and what `this` refers to.
3. How access modifiers hide a property from code outside the class.
4. How a class can implement an interface, so it's guaranteed to have the methods the interface lists.
5. How one class can extend another, and override a method it inherits.

The chapter ends with a summary, and two homework exercises.
